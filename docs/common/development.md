# Neutripic Development Document

## 1. Service Overview

뉴트리픽(Neutripic)은 사용자의 기본 정보, 건강 목표, 복용 중인 약, 특이사항을 바탕으로 건강기능식품 성분 중심의 AI 리포트를 생성하는 서비스이다.

서비스는 제품을 직접 추천하거나 내부에서 상품명, 이미지, 가격, 리뷰를 보여주지 않는다. 대신 iDISK의 증상/성분 데이터와 건강기능식품 기능성원료 인정현황 데이터를 RAG 검색 기반으로 활용하고, LangChain을 통해 추천 성분, 추천 이유, 복용법, 권장 용량, 부작용, 주의사항을 포함한 리포트를 작성한다.

추천 리포트에 포함된 성분은 내부 iHerb 성분 링크 매핑 테이블과 연결될 수 있다. 매핑된 성분을 사용자가 클릭하면 검증된 iHerb 외부 페이지로 이동하지만, 서비스 내부에서는 개별 제품 정보를 표시하지 않는다.

## 2. Core Service Concept

뉴트리픽은 다음 가치를 중심으로 설계한다.

1. 사용자 건강 목표, 복용 약, 특이사항을 반영한 성분 중심 리포트
2. iDISK와 건강기능식품 기능성원료 인정현황 기반 RAG 검색
3. 한국어 사용자 입력을 영어 기반 iDISK 데이터와 매칭하는 다국어 검색
4. 의료 안전성, 서비스 범위, 사용량 제한을 적용하는 AI 가드레일
5. 검증된 iHerb 성분 링크만 제공하는 제한적 외부 연동

AI는 임의로 제품을 추천하지 않는다. 백엔드는 사용자 입력을 정규화하고 RAG 검색 컨텍스트를 구성하며, AI는 이 검증된 컨텍스트 안에서 사용자에게 이해하기 쉬운 리포트와 후속 채팅 답변을 작성한다.

## 3. Target Users

주요 사용자는 다음과 같다.

- 피로, 수면, 눈 건강, 장 건강, 면역, 피부, 스트레스 등 일상적인 건강 목표를 가진 사용자
- 건강기능식품 성분의 기능성, 권장 용량, 주의사항을 알고 싶은 사용자
- 복용 중인 약이나 특이사항 때문에 성분 선택에 주의가 필요한 사용자
- 제품 구매보다 성분 중심의 설명 가능한 리포트를 원하는 사용자
- 생성된 리포트에 대해 후속 질문을 하고 싶은 사용자

## 4. Main User Flow

1. 사용자는 회원가입 또는 로그인한다.
2. 사용자는 건강 목표를 최대 5개까지 선택하고 우선순위를 지정한다.
3. 사용자는 복용 중인 대표 약물과 특이사항을 선택한다.
4. 사용자는 선택지에 없는 복용 약, 질환, 알레르기, 생활 습관 등을 텍스트로 추가 입력할 수 있다.
5. 백엔드는 사용자 입력을 정규화하고, 한국어 입력을 영어 기반 iDISK 검색 질의와 매칭한다.
6. 백엔드는 iDISK 증상/성분 데이터와 건강기능식품 기능성원료 인정현황 데이터를 RAG로 검색한다.
7. 시스템은 복용 약, 특이사항, 서비스 범위, 부적절 입력, 사용량 제한을 기준으로 가드레일을 적용한다.
8. LangChain 기반 AI는 추천 성분, 추천 이유, 복용법, 권장 용량, 부작용, 주의사항을 포함한 리포트를 생성한다.
9. 리포트에는 의료 고지 문구와 전문가 상담 권장 문구를 포함한다.
10. 리포트의 추천 성분이 iHerb 매핑 테이블에 존재하면 성분명을 클릭 가능한 외부 링크로 제공한다.
11. 사용자는 리포트 기반 채팅으로 추가 질문을 할 수 있다.
12. 생성된 리포트와 후속 채팅 내용은 추천 기록으로 저장된다.
13. 사용자는 마이페이지에서 회원 정보, 추천 기록, 내가 작성한 게시글과 댓글을 조회한다.

## 5. Core Features

### 5.1 Health Goal And Safety Survey

사용자는 개선하고 싶은 건강 목표를 선택하고, 복용 약과 특이사항을 함께 입력한다.

건강 목표 예시:

- 피로
- 수면
- 눈 건강
- 장 건강
- 면역
- 피부
- 스트레스
- 혈행
- 관절
- 기억력 또는 집중력

복용 약 선택 예시:

- 고혈압약
- 당뇨약
- 항응고제
- 항우울제
- 피임약
- 진통소염제
- 위장약
- 갑상선약

특이사항 선택 예시:

- 임신 또는 수유
- 간 질환
- 신장 질환
- 심혈관 질환
- 알레르기
- 수술 예정
- 미성년자 또는 고령자

선택지에 없는 정보는 자유 텍스트로 추가 입력할 수 있다. 자유 입력은 RAG 검색과 리포트 생성에 활용되지만, 부적절 입력, 과도한 개인정보, 서비스 범위를 벗어난 요청은 가드레일에서 제한한다.

### 5.2 Korean-to-English RAG Matching

iDISK 데이터는 영어 기반이므로 한국어 사용자 입력을 검색 가능한 영어 질의로 변환해야 한다.

처리 방식:

- 한국어 건강 목표, 증상, 약물, 특이사항을 내부 표준명으로 정규화한다.
- 동의어 사전, 의학 용어 매핑, 번역, 임베딩 검색을 활용해 영어 기반 iDISK 데이터와 매칭한다.
- 매칭 신뢰도가 낮거나 검색 결과의 의미적 관련성이 낮으면 불확실성을 표시하거나 추가 확인 질문을 제공한다.
- RAG 검색 결과는 리포트와 채팅 답변의 근거로 사용한다.

### 5.3 Ingredient Recommendation And Report Generation

뉴트리픽은 제품이 아니라 건강기능식품 성분을 중심으로 리포트를 작성한다.

추천 및 리포트 생성 원칙:

- 사용자의 나이, 성별, 건강 목표, 복용 약, 특이사항을 반영한다.
- 건강 목표의 교집합과 우선순위를 고려해 추천 성분 후보를 선정한다.
- 건강기능식품 기능성원료 인정현황의 기능성, 일일섭취량, 섭취 시 주의사항을 반영한다.
- iDISK의 증상/성분 데이터를 RAG 검색 근거로 활용한다.
- LangChain을 활용해 개인화된 리포트를 생성한다.
- 의학적 진단, 처방, 치료 지시, 약물 중단 지시는 제공하지 않는다.

리포트 예상 구성:

- 사용자 입력 요약
- 핵심 추천 성분 목록
- 성분별 추천 이유
- 기대할 수 있는 기능성
- 복용법 및 권장 용량
- 부작용 가능성
- 섭취 시 주의사항
- 복용 약 또는 특이사항 관련 주의 문구
- 생활 습관 관리 팁
- 건강 정보 제공 목적의 면책 안내

필수 고지 문구:

```text
질환이 있거나 약을 복용 중인 경우 전문가와 상담하세요.
```

### 5.4 Report-Based Chat

사용자는 생성된 추천 리포트에 대해 채팅으로 추가 질문을 할 수 있다.

채팅 범위:

- 리포트에 포함된 성분 설명
- 복용법, 권장 용량, 부작용, 주의사항
- 성분 간 차이
- 사용자 입력과 관련된 일반적인 건강기능식품 정보

제한 범위:

- 질병 진단
- 처방 또는 치료 지시
- 복용 중인 약물의 중단, 변경, 증량, 감량 지시
- 서비스 목적과 무관한 질문
- 제품 구매 유도 또는 특정 제품 효능 보장

채팅 답변은 RAG 검색 근거와 리포트 내용을 기반으로 하며, 의료적 고위험 요청은 전문가 상담 안내로 대체한다.

### 5.5 Guardrails

AI 기능에는 입력, 검색, 응답, 사용량 단계의 가드레일을 적용한다.

가드레일 대상:

- 부적절한 표현
- 프롬프트 인젝션 또는 시스템 명령 탈취 시도
- 과도한 개인정보 입력
- 서비스 범위를 벗어난 요청
- 의료적으로 고위험인 요청
- 허위 근거 또는 과도한 확신 표현
- 제품 구매 유도 문구
- 사용자별 사용량 제한 초과

가드레일에 걸리는 경우 시스템은 리포트나 답변을 생성하지 않거나, 안전한 안내 메시지와 추가 확인 질문을 제공한다. 사용량 제한은 서버 측에서 검증하며 클라이언트 조작으로 우회할 수 없어야 한다.

### 5.6 iHerb Ingredient Link Mapping

iHerb 연동은 상품 표시가 아니라 성분 링크 제공으로 제한한다.

작동 방식:

- 추천 성분명을 내부 표준 성분명으로 정규화한다.
- 내부 iHerb 성분 링크 매핑 테이블에서 검증된 URL을 조회한다.
- 매핑된 URL이 있으면 리포트의 성분명을 클릭 가능한 링크로 제공한다.
- 매핑된 URL이 없으면 성분명만 표시하고 링크는 제공하지 않는다.
- 서비스 내부에서는 iHerb 상품명, 이미지, 가격, 리뷰, 판매자 정보 등 개별 상품 정보를 표시하지 않는다.

매핑 테이블 예시:

| Field | Description |
| --- | --- |
| `ingredient_name_ko` | 한국어 성분명 |
| `ingredient_name_en` | 영어 성분명 |
| `normalized_name` | 내부 매칭용 표준명 |
| `iherb_url` | 검증된 iHerb 카테고리, 검색, 성분 페이지 URL |
| `iherb_category_name` | iHerb 카테고리명 |
| `is_active` | 링크 노출 여부 |
| `last_verified_at` | 마지막 검증 일자 |

예시 데이터:

```text
ingredient_name_ko: L-아르기닌
ingredient_name_en: L-Arginine
normalized_name: l_arginine
iherb_url: https://kr.iherb.com/c/amino-acids?cids=1674
iherb_category_name: Amino Acids
is_active: true
```

외부 링크는 서버에 저장된 허용 URL만 사용하며, 사용자 입력값을 직접 URL로 변환하지 않는다.

### 5.7 Report History And My Page

생성된 리포트와 후속 채팅 내용은 사용자의 추천 기록으로 저장된다.

추천 기록 기능:

- 추천 기록 저장
- 추천 기록 목록 조회
- 추천 기록 상세 조회
- 추천 기록 제목 수정
- 추천 기록 삭제

마이페이지 기능:

- 회원 정보 조회
- 회원 정보 수정
- 회원 탈퇴
- 추천 기록 조회
- 내가 작성한 게시글 조회
- 내가 작성한 댓글 조회

### 5.8 Community

사용자는 게시판을 통해 건강 고민, 영양제 경험, 추천 후기 등을 공유할 수 있다.

기본 기능:

- 게시글 작성, 조회, 수정, 삭제
- 댓글 작성, 수정, 삭제
- 답글 작성, 수정, 삭제
- 게시글 추천 및 추천 취소
- 최신순 또는 추천순 정렬

비회원은 메인 페이지와 커뮤니티 목록만 조회할 수 있으며, AI 추천과 게시글/댓글 작성은 사용할 수 없다.

## 6. System Architecture

뉴트리픽은 프론트엔드, Django 백엔드, AI/RAG 레이어, 데이터 저장소로 구성한다.

```text
[Frontend]
  - 회원/인증 화면
  - 건강 목표 설문 UI
  - 복용 약/특이사항 입력 UI
  - 추천 리포트 화면
  - 리포트 기반 채팅 UI
  - 추천 기록/마이페이지
  - 커뮤니티
        |
        v
[Backend - Django REST API]
  - 사용자 인증 및 JWT 검증
  - 사용자별 데이터 분리
  - 건강 목표/복용 약/특이사항 저장
  - 한국어 입력 정규화
  - 성분 추천 후보 계산
  - 가드레일 및 사용량 제한
  - 추천 리포트/채팅 저장
  - iHerb 성분 링크 매핑 조회
  - 커뮤니티 API
        |
        v
[AI/RAG Layer]
  - LangChain 기반 리포트 생성
  - 한국어-영어 검색 질의 변환
  - iDISK 증상/성분 데이터 검색
  - 기능성원료 인정현황 데이터 검색
  - 리포트 기반 채팅 응답 생성
  - 입력/응답 가드레일 검증
        |
        v
[Data Sources]
  - iDISK 증상/성분 데이터
  - 건강기능식품 기능성원료 인정현황
  - 내부 성분 정규화/동의어 데이터
  - iHerb 성분 링크 매핑 데이터
        |
        v
[Database]
  - 사용자
  - 건강 목표
  - 복용 약/특이사항
  - 성분 및 기능성 원료
  - RAG 문서/임베딩 메타데이터
  - 추천 리포트
  - 리포트 채팅
  - iHerb 성분 링크 매핑
  - 게시글, 댓글, 답글, 추천
```

## 7. Data Flow

```text
1. 사용자 입력
   - 나이, 성별
   - 건강 목표 및 우선순위
   - 복용 약 선택
   - 특이사항 선택
   - 자유 텍스트 추가 입력

2. 입력 정규화 및 가드레일
   - 한국어 입력 표준화
   - 부적절 입력, 범위 외 요청, 과도한 개인정보 탐지
   - 사용자별 사용량 제한 확인

3. 한국어-영어 검색 매칭
   - 동의어/의학 용어 매핑
   - 영어 검색 질의 변환
   - iDISK 데이터와 의미 기반 매칭

4. RAG 검색

   - 기능성, 일일섭취량, 주의사항 컨텍스트 구성

   - 의료 고지 문구 포함

   - 추천 성분을 내부 표준명으로 정규화
   - 검증된 iHerb URL 조회
```

## 8. Differentiation

### 8.1 Ingredient-Centered Report

뉴트리픽은 상품 판매형 추천 서비스가 아니라 성분 중심 리포트 서비스이다. 서비스 내부에서 특정 제품을 노출하지 않고, 성분의 기능성, 용량, 부작용, 주의사항을 설명한다.

### 8.2 RAG-Based Grounding

AI는 자체 지식만으로 답하지 않고, iDISK와 건강기능식품 기능성원료 인정현황에서 검색된 근거를 바탕으로 리포트와 채팅 답변을 작성한다. 가능한 경우 참조한 데이터 출처 또는 근거 데이터를 추적할 수 있어야 한다.

### 8.3 Korean-to-English Matching

영어 기반 iDISK 데이터를 한국어 사용자 입력과 연결하기 위해 번역, 동의어 사전, 의학 용어 매핑, 임베딩 검색을 활용한다. 매칭 신뢰도가 낮은 경우 불확실성을 표시하거나 추가 확인 질문을 제공한다.

### 8.4 Safety Guardrails

복용 약, 질환, 임신/수유, 알레르기 등 위험 요인을 반영한다. AI는 진단, 처방, 치료 중단 또는 약물 변경을 지시하지 않으며, 고위험 상황에서는 전문가 상담을 권장한다.

### 8.5 Verified External Links

iHerb 연동은 검증된 성분 링크 매핑 테이블을 통해서만 제공한다. 사용자 입력을 직접 URL로 만들지 않으며, 링크 변경에 대응할 수 있도록 매핑 데이터를 별도로 관리한다.

## 11. MVP Scope

초기 MVP는 다음 범위로 제한한다.

- 회원가입, 로그인, 로그아웃
- JWT 인증
- 건강 목표 선택 및 우선순위 입력
- 나이, 성별 입력
- 대표 복용 약 선택
- 대표 특이사항 선택
- 추가 정보 텍스트 입력
- 한국어 입력 정규화 및 영어 기반 iDISK 매칭
- iDISK 증상/성분 데이터 RAG 검색
- 건강기능식품 기능성원료 인정현황 기반 용량/주의사항 검색
- LangChain 기반 추천 리포트 생성
- 입력/응답 가드레일
- 사용자별 리포트 생성 및 채팅 사용량 제한
- iHerb 성분 링크 매핑 테이블
- 추천 성분별 검증된 iHerb 외부 링크 제공
- 리포트 저장 및 추천 기록 조회
- 리포트 기반 채팅
- 마이페이지
- 게시글 CRUD
- 댓글/답글 CRUD
- 게시글 추천 및 정렬
- 관리자 회원/게시글/댓글 관리
- RESTful API 설계

초기 MVP에서 제외하거나 후순위로 둘 수 있는 기능:

- 소셜 로그인
- 알림 기능
- 결제
- 복용 알림
- 병원 또는 약국 연계
- 고도화된 약물 상호작용 분석
- 사용자가 직접 제품명, 브랜드명, 판매처로 검색하는 기능
- 서비스 내부 상품명, 이미지, 가격, 리뷰 표시
- 쿠팡 API 상품 연동

## 12. Safety And Disclaimer

뉴트리픽은 질병을 진단하거나 치료하는 서비스가 아니다. 추천 리포트와 채팅 답변에는 건강 정보 제공 목적임을 명확히 표시해야 한다.

필수 안내:

- 본 리포트는 건강 정보 제공 목적이다.
- 질병 진단, 치료, 처방을 대체하지 않는다.
- 임신, 수유, 만성질환, 복용 중인 약물이 있는 경우 전문가와 상담해야 한다.
- 특정 성분 섭취 후 이상 반응이 있으면 복용을 중단하고 전문가와 상담해야 한다.
- AI 답변은 의학적 진단이나 처방이 아니며, 필요 시 전문가 상담을 권장한다.
- 서비스 내부에서는 특정 제품의 치료 효과를 보장하지 않는다.
- iHerb 링크는 외부 참고 링크이며, 뉴트리픽이 특정 제품 구매를 권장하거나 효능을 보장하지 않는다.
