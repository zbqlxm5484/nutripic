# User Flow

이 문서는 `docs/common/development.md`의 Main User Flow와 MVP Scope를 프론트엔드 사용자 경험 기준으로 정리한다.

## 1. 핵심 사용자 목표

사용자는 자신의 건강 고민, 기본 정보, 복용 약, 특이사항을 입력하고 RAG 기반 추천 성분과 AI 개인화 리포트를 확인한다. 이후 리포트 기반 채팅으로 후속 질문을 할 수 있으며, 생성된 리포트와 채팅은 추천 기록으로 저장되어 마이페이지에서 다시 확인할 수 있다.

## 2. 주요 사용자

- 어떤 건강기능식품 성분이 필요한지 모르는 사용자
- 피로, 수면, 눈 건강, 장 건강, 면역, 피부, 스트레스 등 여러 건강 목표를 함께 관리하고 싶은 사용자
- 복용 중인 약이나 특이사항 때문에 성분 선택에 주의가 필요한 사용자
- 추천 이유, 기능성, 권장 용량, 부작용, 주의사항을 함께 확인하고 싶은 사용자
- 추천 리포트에 대해 후속 질문을 하고 싶은 사용자
- 건강 고민이나 영양제 경험을 커뮤니티에서 공유하고 싶은 사용자

## 3. 기본 추천 플로우

```text
홈
  -> 회원가입 또는 로그인
  -> 추천 설문 시작
  -> 건강 목표 선택 및 우선순위 지정
  -> 복용 약 선택
  -> 특이사항 선택
  -> 추가 정보 직접 입력
  -> 추천 리포트 생성 요청
  -> 추천 결과 확인
  -> 리포트 기반 채팅
  -> 마이페이지에서 추천 기록 조회
```

### 3.1 홈 진입

사용자는 홈에서 서비스 목적을 확인하고 추천 설문을 시작한다.

주요 행동:

- 추천 시작
- 로그인
- 회원가입
- 게시판 이동

비회원이 추천 시작을 누르면 로그인 페이지로 이동하고, 로그인 성공 후 추천 설문으로 복귀한다.

### 3.2 인증

AI 추천, 추천 결과 조회, 리포트 기반 채팅, 마이페이지 조회, 게시글 작성 등 사용자 데이터가 필요한 기능은 로그인 상태를 요구한다.

기본 흐름:

```text
비로그인 사용자
  -> 로그인 또는 회원가입
  -> 인증 성공
  -> 직전에 시도한 작업 또는 홈으로 이동
```

인증이 필요한 대표 기능:

- 리포트 생성
- 추천 기록 조회
- 리포트 기반 채팅
- 게시글 작성, 수정, 삭제
- 댓글/답글 작성, 수정, 삭제
- 게시글 추천 및 추천 취소

### 3.3 추천 설문

사용자는 개선하고 싶은 건강 목표를 카드 또는 체크박스 UI로 선택하고, 선택한 목표의 우선순위를 지정한다.

필수 입력:

- 건강 목표 1개 이상, 최대 5개
- 목표 우선순위
- 나이
- 성별

선택 입력:

- 대표 복용 약
- 임신 또는 수유, 간/신장 질환, 심혈관 질환, 알레르기, 수술 예정 등 특이사항
- 선택지에 없는 복용 약, 질환, 알레르기, 생활 습관 등 추가 정보

프론트엔드 검증:

- 건강 목표를 1개 이상 선택하지 않으면 다음 단계로 진행하지 않는다.
- 건강 목표를 5개 초과 선택할 수 없다.
- 선택한 건강 목표의 우선순위가 중복되지 않도록 한다.
- 성별과 나이를 입력하지 않으면 리포트 생성 요청을 막는다.
- 나이는 숫자 범위 입력으로 제한한다.

### 3.4 리포트 생성

사용자가 설문을 제출하면 백엔드가 한국어 입력을 정규화하고, iDISK 및 건강기능식품 기능성원료 인정현황 데이터를 RAG로 검색한 뒤, AI가 개인화 리포트를 생성한다.

사용자에게 보여줄 상태:

- 생성 중 로딩 상태
- 단계별 진행 안내
- 생성 실패 에러 상태
- 재시도 액션
- 사용량 제한 안내
- 가드레일 차단 안내
- 건강 정보 제공 목적 안내

### 3.5 추천 결과 확인

사용자는 추천 리포트 화면에서 입력 요약, 추천 성분, 성분별 이유, 기능성, 권장 용량, 주의사항, 부작용 가능성, 생활 습관 팁을 확인한다.

추천 결과 화면의 핵심 정보:

- 사용자 입력 요약
- 핵심 추천 성분 목록
- 성분별 추천 이유
- 식약처 기준 기능성 설명
- 일일 섭취량과 섭취 시 주의사항
- 부작용 가능성
- 생활 습관 관리 팁
- 면책 안내
- 검증된 iHerb 성분 외부 링크

주요 행동:

- 리포트 기반 채팅
- 검증된 성분 링크 열기
- 다시 설문하기
- 마이페이지 이동

주의:

- 서비스 내부에서는 iHerb 상품명, 이미지, 가격, 리뷰를 표시하지 않는다.
- iHerb 링크는 백엔드가 검증한 성분 URL이 있는 경우에만 표시한다.
- 링크가 없는 성분은 성분명만 표시한다.

### 3.6 리포트 기반 채팅

사용자는 생성된 리포트에 대해 추가 질문을 할 수 있다. 채팅은 리포트 내용과 RAG 근거를 기반으로 답변해야 하며, 의료적으로 고위험인 요청은 안전 안내로 대체한다.

허용 질문:

- 리포트에 포함된 성분 설명
- 복용법, 권장 용량, 부작용, 주의사항
- 성분 간 차이
- 사용자 입력과 관련된 일반적인 건강기능식품 정보

제한 질문:

- 질병 진단
- 처방 또는 치료 지시
- 복용 중인 약물의 중단, 변경, 증량, 감량 지시
- 특정 제품 구매 유도 또는 효능 보장

### 3.7 리포트 저장과 재조회

생성된 리포트와 후속 채팅은 추천 기록으로 저장된다. 저장된 리포트는 마이페이지 또는 추천 기록 목록에서 생성일 기준으로 조회한다.

마이페이지 흐름:

```text
마이페이지
  -> 저장된 리포트 목록
  -> 리포트 상세
  -> 리포트 기반 채팅 재조회
  -> 리포트 제목 수정
  -> 리포트 삭제
```

목록에서 제공할 정보:

- 생성일
- 선택 건강 목표
- 주요 추천 성분
- 상세 보기
- 제목 수정
- 삭제

### 3.8 커뮤니티 이용

사용자는 게시판에서 건강 고민, 추천 후기, 영양제 경험을 공유할 수 있다.

기본 흐름:

```text
게시판 목록
  -> 게시글 상세
  -> 댓글 확인
  -> 게시글 작성 또는 댓글 작성
  -> 작성 완료 후 상세 또는 목록으로 이동
```

로그인 필요 행동:

- 게시글 작성
- 게시글 수정
- 게시글 삭제
- 댓글 작성, 수정, 삭제
- 답글 작성, 수정, 삭제
- 게시글 추천 및 추천 취소

## 4. 예외 플로우

### 4.1 비로그인 상태에서 추천 시작 시도

```text
홈 또는 커뮤니티
  -> 추천 시작 클릭
  -> 로그인 필요 안내
  -> 로그인
  -> 추천 설문으로 이동
```

### 4.2 리포트 생성 실패

```text
설문 제출
  -> 리포트 생성 중
  -> API 또는 AI 생성 실패
  -> 실패 안내
  -> 재시도 또는 설문 수정
```

### 4.3 가드레일 또는 사용량 제한

부적절 입력, 과도한 개인정보, 서비스 범위 밖 요청, 의료 고위험 요청, 사용량 제한 초과는 리포트 생성 또는 채팅 응답 전에 차단한다.

```text
설문 제출 또는 채팅 전송
  -> 가드레일/사용량 검증
  -> 차단 안내 또는 추가 확인 질문
  -> 입력 수정 또는 다음 사용 가능 시점 안내
```

### 4.4 iHerb 성분 링크 없음

추천 성분에 매핑된 iHerb 링크가 없더라도 리포트는 정상 표시한다.

```text
추천 결과
  -> 리포트 표시
  -> 매핑된 성분은 외부 링크 표시
  -> 미매핑 성분은 성분명만 표시
```

### 4.5 저장된 리포트가 없는 경우

```text
마이페이지
  -> 저장 리포트 없음
  -> 추천 설문 시작 CTA
```

### 4.6 게시글 또는 리포트 접근 권한 없음

수정, 삭제 권한이 없거나 로그인 상태가 만료된 경우 권한 안내를 보여주고 안전한 페이지로 이동한다.

```text
권한 필요 액션
  -> 권한 없음 안내
  -> 로그인 또는 이전 페이지 이동
```

## 5. 안전 안내 원칙

추천 리포트와 리포트 기반 채팅에는 다음 안내가 반복적으로 노출되어야 한다.

- 본 리포트는 건강 정보 제공 목적이다.
- 질병 진단, 치료, 처방을 대체하지 않는다.
- 임신, 수유, 만성질환, 복용 중인 약물이 있는 경우 전문가와 상담해야 한다.
- 특정 성분 섭취 후 이상 반응이 있으면 복용을 중단하고 전문가와 상담해야 한다.
- AI 답변은 의학적 진단이나 처방이 아니며, 필요 시 전문가 상담을 권장한다.
- iHerb 링크는 외부 참고 링크이며, 뉴트리픽이 특정 제품 구매를 권장하거나 효능을 보장하지 않는다.
